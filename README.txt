City Drive Mobile
=================
نسخة موبايل 2D خفيفة جدًا.

المشروع يحتاج جهاز كمبيوتر Linux/macOS أو Windows مع WSL لبناء APK باستخدام Buildozer.
الخطوات الأساسية:

1) ثبّت Buildozer وKivy حسب وثائقهم.
2) ادخل مجلد المشروع.
3) نفّذ:
   buildozer -v android debug
4) ستجد ملف APK داخل مجلد bin/.

لتثبيته على الهاتف، انقل APK إلى Realme C21 وافتحه.

التحكم:
▲ ▼ ◀ ▶ = الحركة والقيادة
E = ركوب/نزول من السيارة

هذه نسخة Prototype أولى ومصممة لتكون خفيفة.
